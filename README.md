# Wscan

An iOS app that helps you understand German official letters (Behördenpost).
Scan or paste a letter, get a plain-language summary, and never miss a deadline.

All analysis runs on-device with Apple's Foundation Models — letters never leave your phone.

> 🚧 Work in progress

**Stack:** SwiftUI · Swift 6 · SwiftData · Foundation Models · Swift Testing · XCUITest
